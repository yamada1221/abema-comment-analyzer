# ABEMA Comment Analyzer

ABEMAのコメントをブラウザ内で記録・集計し、投稿者単位で分析・ミュートするChrome拡張です。

## ダウンロード

**[最新版をZIPでダウンロード](https://github.com/yamada1221/abema-comment-analyzer/archive/refs/heads/main.zip)**

ZIPを展開して、Chromeの「パッケージ化されていない拡張機能を読み込む」から展開したフォルダを選択してください。

## 主な機能

- コメントをローカルに最大24時間保存
- 分析対象を「直近30分」「直近2時間」など任意に指定
- ABEMAのコメント欄を上へ遡って過去コメントを取得
- 分析画面からABEMAのコメント欄を自動で開けるかテスト
- 指定した番組の監視時間帯にABEMAを自動起動し、番組名検出中だけコメントを記録
- 投稿者ID別ランキング
- 投稿者ごとのコメント一覧
- ユーザーID単位の複数タグ・タグ検索・絞り込み
- 指定時間幅に応じたコメント数推移グラフ
- 投稿者単位のリアルタイムミュート
- 連投・同文/類似連投・NGワードによる自動ミュート
- 自動ミュート理由と該当コメントの履歴表示
- 自動判定から除外するユーザー（ホワイトリスト）
- ミュート済みユーザーのコメント傾向を端末内で学習し、新しいミュート候補を検出
- 学習型ミュートの候補表示 / 高スコア自動ミュート
- バージョン間の引継ぎファイル書き出し / 読み込み
- JSON / CSVエクスポート

## インストール

1. 上の「最新版をZIPでダウンロード」を押します。
2. ZIPを展開します。
3. Chromeで `chrome://extensions/` を開きます。
4. 「デベロッパーモード」をONにします。
5. 「パッケージ化されていない拡張機能を読み込む」を押し、展開したフォルダを選択します。
6. ABEMAの番組ページを開き、コメント欄を表示します。

## バージョンアップとデータ引継ぎ

### 同じフォルダを使って更新する場合

既存の拡張フォルダへ新版のファイルを上書きし、`chrome://extensions/` で「更新」を押してください。同じ拡張IDのままなら `chrome.storage.local` のデータはそのまま利用されます。

v0.5.0以降は保存形式のバージョン番号を持ち、同じ拡張ID内では必要なマイグレーションを自動実行します。

### 別フォルダへ新版を入れる場合

未パッケージ拡張はフォルダが変わると別の拡張IDになる場合があります。その場合は以下で引き継げます。

1. 旧版の分析画面を開く。
2. 「引継ぎデータを書き出す」を押してJSONファイルを保存する。
3. 新版をインストールする。
4. 新版の分析画面で「引継ぎデータを読み込む」を押す。
5. 旧版で保存したJSONを選択する。

引継ぎ対象:

- 保存コメント
- 手動ミュート一覧
- ユーザータグ（コメントの保存期限後も保持）
- 自動ミュート設定
- NGワード
- ホワイトリスト
- 自動ミュート履歴
- 学習型自動ミュートの管理情報
- 分析時間設定
- コメント記録ON/OFF
- 指定番組の自動起動設定

分析画面には現在の拡張バージョンと保存形式番号も表示されます。

## コメント欄の自動オープンテスト

分析画面の「コメント欄を自動で開くテスト」を押すと、開いているABEMAタブを検出し、コメントアイコンや「コメント」ラベルを持つボタンを探してコメント欄を開きます。

成功判定はクリック実行だけではなく、コメント入力欄・コメント一覧・ボタンの開閉状態などから、実際にコメント欄が開いたことを確認して行います。表示中のモーダルに「後で」ボタンがある場合は、そのモーダル内のボタンだけを先に閉じます。

この機能は、将来の「指定番組の時間になったらABEMAを自動起動 → コメント欄を自動で開く → 記録開始」の前段階テストです。

## 指定番組の自動起動

分析画面の「指定番組の自動起動」で、番組名、ABEMA URL、監視曜日、監視開始・終了時刻を設定できます。

初期値は以下です。

- 番組名: 報道ステーション
- URL: https://abema.tv/now-on-air/abema-news
- 曜日: 火〜土
- 監視時間帯: 00:00〜02:00
- 拡張が自動で開いたタブは終了後に閉じる
- 起動したタブは前面に出さない

監視時間帯になるとバックグラウンド処理がABEMA NEWSを開き、現在のABEMA画面から指定番組名を確認します。番組名を検出した時点でコメント記録をONにし、「後で」モーダルを必要に応じて閉じた上でコメント欄を自動で開きます。

番組名を一度検出して記録を開始した後は、ABEMA側の表示切替などで番組名を一時的に見失っても記録を継続します。監視時間帯を過ぎると終了し、自動起動前のコメント記録ON/OFF状態へ戻します。

分析画面の「現在のABEMAで番組名を確認」を使うと、自動記録を開始せずに現在のABEMAタブで番組名判定だけを試せます。

初期値の時間帯は変更可能です。ABEMA側の編成変更に備え、固定時刻ではなく設定値として保存します。

## 過去コメントの取得

分析画面の「過去コメントを読み込む」を押すと、開いているABEMAタブを自動検出し、そのタブのコメント欄を上方向へ遡って過去コメントを取得します。

ABEMAタブは開いている必要があり、コメント欄も表示しておく必要があります。

## 自動ミュート

分析画面の「自動ミュート」で有効化します。初期状態では誤判定防止のためOFFです。

設定できるルール:

- 高頻度投稿: 例 30秒以内に8件でミュート
- 同文・類似連投: 空白・記号などを正規化した上で、例 60秒以内に3回でミュート
- NGワード: 1行1件で登録し、部分一致したコメントをしたユーザーをミュート
- 除外ユーザー: 1行1ユーザーIDで登録すると自動判定しません

自動ミュートされたユーザーは通常のミュート一覧にも入り、分析画面から解除できます。判定理由・該当コメント・時刻は自動ミュート履歴に保存します。

## 学習型ミュート

ミュート済みユーザーのコメントを学習例として、未ミュートユーザーのコメント傾向がどの程度近いかを端末内で計算します。

- 日本語の形態素解析や外部AI APIは使わず、文字2〜3gram + TF-IDFで特徴を作ります。
- 通常ユーザーにも多い表現は減点し、ミュート済みユーザー側に特徴的な表現を重視します。
- 1コメントだけでは判定せず、ユーザーごとの最低コメント数を設定できます。
- まず候補だけ表示し、確認して手動ミュートできます。
- 必要なら高スコアの候補だけ自動ミュートできます。
- 自動ミュートで新たに追加されたユーザーは、そのまま次の学習元には使わないため、誤判定が連鎖しにくい設計です。
- 候補ごとに類似度と、判定に寄与した文字パターンを表示します。
- ホワイトリストへ追加すれば、以後の候補判定・自動ミュートから除外できます。

学習型ミュートは初期状態OFFです。分析画面で有効化し、候補しきい値と自動ミュートしきい値を調整してください。コメント内容と学習処理は外部へ送信されません。

## ユーザータグ

投稿者ランキングでユーザーを選び、「ユーザータグ」に好きな名前を入力して「タグを保存」を押します。

- カンマ・読点・改行で複数のタグを区切れます。1タグ32文字、1ユーザー12個までです。
- 「要観察」「定型文」「掛け合い」「連投」はボタンでも追加できます。同じタグは重複登録されません。
- ランキングにタグが表示され、「タグで絞り込み」や検索欄で探せます。
- 「タグ付きユーザー」または個別タグを選ぶと、現在の分析時間内にコメントがないユーザーも0件で表示します。
- 未収集のIDも「IDを指定してタグを編集」から登録できます。
- タグを外して保存すると削除されます。「すべて外す」は「タグを保存」で確定します。
- タグはミュートとは独立しています。付けただけではミュートや学習判定は変わりません。
- コメントの24時間保存期限を過ぎてもタグは残ります。ユーザーIDが変わった場合は別ユーザーとして扱います。
- JSON・CSVのコメント書き出しにも、その時点のユーザータグを含めます。コメントがないユーザーのタグまで保存する場合は、引継ぎデータを書き出してください。
- 引継ぎファイルに全ユーザータグを含めます。タグのない旧版の引継ぎファイルを読む場合は現在のタグを保持します。タグを含む新版の引継ぎではタグ一覧も復元元で置き換えます。
- 編集中にコメントが追加されてもタグの入力は保持されます。別画面で同じユーザーのタグが変更された場合は、保存時に知らせます。

## データについて

コメントデータ、ミュート設定、自動ミュート設定は `chrome.storage.local` に保存され、外部サーバーには送信しません。

引継ぎファイルにはこれらのデータが含まれるため、第三者へ渡さないでください。

高コメント量の番組では最大25,000件の保存上限に先に達する場合があります。


## v0.9.0: 学習用データの継続保存

学習型ミュートを有効にすると、ミュート済みユーザーの学習用サンプルを閲覧履歴と別に保存します。閲覧履歴が24時間で消えても学習元を保持できます。旧版ですでに失われたコメントは復元できません。

- 最大200人、1人40件。新しい投稿を優先し、各サンプルは正規化済みの最大160文字です。端末内にのみ保存します。
- 学習元ごとの重みは最終サンプルから30日で半減。180日を超えたサンプルは対象外になり、次回の保存更新で削除します。類似度は確率ではなく、同じ話題による誤判定は引き続きあり得ます。
- ミュート解除・ホワイトリスト指定でその人の保存サンプルを削除。学習による自動ミュート済みユーザーは学習元にしません（既存のルール型自動ミュートは学習元に含みます）。
- 学習を無効にすると新しいサンプルの蓄積を停止します。既存サンプルは保持しますが、解除・除外・期限は反映します。
- 候補判定と一般ユーザーとの比較には現在の保存コメントを使います。古いユーザーを候補として再表示しません。
- 引き継ぎファイルに学習用データを含めます（保存形式3）。旧形式の取り込みでは既存の学習用データを保持し、復元したミュート・除外設定に合わせて整理します。

更新前に引き継ぎファイルを保存してください。更新後はABEMAタブを再読み込みしてください。
