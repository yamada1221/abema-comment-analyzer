# Chromeウェブストア審査用の確認手順

対象：ABEMAコメント分析（非公式）v0.13.2。申請時の「テスト手順」に以下を転記できます。専用のABEMAログイン情報は用意していません。

## 実放送に接続しない確認

新しいテスト用Chromeプロファイルを使用してください。以下のサンプル読み込みは保存済みデータを上書きするため、普段のデータがある環境では実行しないでください。

1. 拡張機能を追加し、ポップアップで記録がOFFであること、記録開始前にデータの説明があることを確認します。
2. 「はじめての使い方・データの取り扱い」からガイド・データの説明を開けることを確認します。
3. [架空データのJSONサンプル](https://raw.githubusercontent.com/yamada1221/abema-comment-analyzer/experiment/monetization-validation/store-assets/reviewer-demo-v0.13.2.json)をファイルとして保存します。実際のABEMAコメントや実在の投稿者IDは含みません。
4. ポップアップから「分析画面」を開き、「更新・バージョン引継ぎ」の「引継ぎデータを読み込む」でサンプルを選びます。上書き確認を読んで復元を許可します。記録と番組自動起動はOFFのままです。
5. 上部の件数がコメント18件・ユーザー6人になったことを確認します。必要なら「保存分すべて」を押します。サンプルの日時は固定の架空データです。
6. 「コメント検索」の「検索語句」欄で「宇宙」を検索すると6件に一致します。「条件をクリア」で18件に戻します。
7. 「投稿者ランキング」の `demo_user_03` を選びます。タグ欄の「科学, メモ」を変更・保存し、再読み込み後も保持されることを確認できます。「この投稿者をミュート」からミュートし、解除できます。実放送未接続のため、ここではミュート設定の保存・解除の確認です。
8. 「保存コメントのリプレイ」で「現在の検索結果を読み込む」を押し、再生・一時停止・「次のコメントへ」でサンプルを表示できます。映像・音声を再生する機能ではありません。

この手順はABEMAへの接続や地域制限の回避を行いません。ストア用スクリーンショットも同じサンプルを使用しています。サンプルはストアの実行用ZIPには含めず、自動で読み込みません。

## 実放送の確認

日本国内でABEMAの無料放送を視聴できるPC版Chromeを使用してください。サービス側がログイン等を求める場合は、その案内に従ってください。地域制限を回避する手段は提供していません。

1. ABEMAの視聴ページでコメント欄を開きます。拡張機能のポップアップでデータの説明を読んで「記録を開始」を押し、ABEMAタブを再読み込みします。
2. コメントが流れると、ポップアップ・分析画面の保存件数が増えます。受信できるコメントだけを記録し、映像や音声は保存しません。
3. 「記録を停止」を押し、60秒以上待って新着保存が停止することを確認します。自動記録の設定は初期状態でOFFです。

国内の本人確認では、初期OFF、実コメント記録、停止後60秒以上の件数保持、本文検索、タグ保存、リプレイ、ミュート解除が成功したとの報告を受けています。Codexが実放送を直接操作した結果ではありません。自動番組の起動・復旧や署名済みストア更新の本番確認を含みません。

## データと権限の補足

コメント本文・投稿者ID・日時・対象ページ情報・利用者のタグ等を端末内に保存します。開発者管理サーバーへの自動送信や広告・解析SDKはありません。`storage`、`unlimitedStorage`、`alarms` と `https://abema.tv/*` のホスト権限を要求します。外部から実行コードを読み込みません。ABEMA公式とは提携していません。

正式なポリシーURL・公開窓口と、管理画面での実際の申告内容は申請前に確定します。この文書の作成は申請・公開・ABEMAからの承認を意味しません。
