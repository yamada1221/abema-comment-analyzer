# ABEMAコメント分析：小規模収益化検証（一般配布前の準備）

作成日: 2026-10-17  
状態: **準備・評価のみ**。一般配布の告知、有料機能、決済、ライセンス制御の実装は行わない。

この計画書は公開GitHubリポジトリ内の開発ブランチに置いているため、URLを知っている人は閲覧できます。非公開のマーケティング資料や機密情報は含めません。

## 目的と仮説

既存のChrome拡張を使い、「ABEMAのコメントを後から検索・再生し、投稿者をタグ付け・ミュートできること」に継続需要があるか確かめる。

- 初期目標：**月1,000円相当の売上に届く見込みがあるか検証**（売上保証ではない）。
- 最初の利用者向け価値：コメント単位の検索、コメントのリプレイ、投稿者タグ、ミュートと解除、自動起動・記録。
- 2026-10-17時点のコード基準：`main` の manifest v0.13.1。外部販売・定期課金機能は未実装。
- 個人用の番組自動起動初期設定（ABEMA NEWS、CNNjなど）はそのまま不特定多数へ配布する仕様にしない。初回起動時は説明と利用者選択を検討する。

## 検証ブランチの進捗（2026-10-19）

- 新規インストール時の記録を明示開始型に変更。アップデート時の記録設定は維持（`background.js`）。
- ポップアップから開ける案内ページ `guide.html`、プライバシー説明 `privacy.html` を追加。
- 新規インストール・更新時設定保持の回帰テストを追加。2026-10-20の引継ぎ時点で単体172件と模擬Chromeを含むCIの成功を確認。v0.13.2候補版の最新結果は[配布準備記録](distribution-readiness.md)を参照。
- 配布・検証の未完了項目は [`distribution-readiness.md`](distribution-readiness.md) に整理。
- これらはすべて `experiment/monetization-validation` ブランチの変更。`main` には未反映。

## 検証の段取り

### 0. 配布前に満たす条件（必須）

- [ ] 日本国内のChrome＋ABEMA本番画面で、記録開始・コメント欄表示・コメント保存・検索・リプレイ・ミュート・復旧を確認。クラウド環境は地域制限のため実放送確認できていない（`AGENTS.md`）。
- [x] `npm test` と `npm run test:browser` を実行し、模擬環境のテストとして結果を区別して記録（詳細は配布準備記録）。
- [x] 初回利用者向けの暫定手順書（`guide.html`）を用意。録画ではなく**コメント本文のみの記録**であり、タブを閉じると取得停止する等の制限を説明。国内Chromeでの動作確認は残る。
- [ ] データ保存、権限、通信をコード監査し、最新の実装に即したプライバシー説明を用意。READMEの「端末内で保存・外部送信しない」はリリース前に実コードと照合。
- [ ] ABEMAとの非提携表記、ABEMAの利用規約・コメントの権利・Chrome Web Storeのポリシーを確認。公開用素材に公式ロゴを無断使用しない。
- [ ] 既存利用者の設定（記録、タグ、ミュート、引継ぎ）を壊さない。第三者配布時に個人用自動起動スケジュールを強制しない。

### 1. 小規模・無料の需要検証（公開前に利用者と範囲を決める）

配布を利用者が承認した場合に限り、知人や関心のある少人数へ**無料版**を案内。ユーザーのコメントデータを収集しない。簡単な任意アンケートで十分。

- 目安：**5〜10人**に試してもらい、**約2週間**観察（人数と期間は試験用の仮置き）。
- 取得するもの：インストールできたか、使えた機能、7日後も使ったか、最も便利だった機能、支援・購入に意欲があるか、改善希望。投稿本文・投稿者ID・視聴履歴は受け取らない。
- 判断目安：10人中5人が1週間後も使い、3人以上から「便利」「支援したい」「買いたい」等の具体的反応がある。未達なら課金機能を作る前にオンボーディングと需要を見直す。
- 利用者数や売上が自動で計測できる仕組みは**現時点ではない**。同意のないテレメトリーは追加しない。

### 2. 収益化方式の選択（需要確認後）

**第一候補：寄付・サポーター型（任意）**

- 全機能は無料のまま。広告挿入やコメントデータ送信は行わない。
- 任意で一回300〜1,000円程度の支援を検討。支払先、税務、返金案内の設定は運営者が確認してから。
- 目標例：一回500円の支援が月2件で売上1,000円。継続性はないため、月次売上は変動する。

**第二候補：買い切り追加機能**

- 継続需要がある高度機能を確認できた場合のみ検討。既存機能を突然有料化しない。
- Chrome拡張がローカル処理主体なので、認証サーバーやサブスク基盤を先に導入しない。

### 3. 提供方法（必要になった時点で実行）

- GitHub ZIPだけの配布は初心者には難しい。正式配布を進めるならChromeウェブストアに登録（登録料・審査あり）。
- ストアに申請する前に、公開ページの説明文・スクリーンショット・アイコン・連絡窓口・プライバシーポリシー・権限の理由を整備する。
- 公開・決済開始・Chromeウェブストア登録料の支払いは、この実験計画の範囲外。

## 表示用説明文（ドラフト）

> **ABEMAコメント分析（非公式）**  
> ABEMAの視聴中に表示されるコメントを、自分のChromeブラウザ内で保存・検索・振り返るための拡張機能です。コメント本文の検索、投稿者タグ、ミュート、コメントの時系列リプレイなどに対応します。  
> 取得可能なコメントはABEMA側の表示・通信に依存します。映像の保存機能はありません。ABEMA公式とは関係ありません。動作条件やプライバシーの説明をご確認ください。

## 開発・配布の禁止事項（この段階）

- 既存コメント、ミュート、タグを消したり有料化のために利用不能にしない。
- ユーザー許可なしに一般公開、Chrome Web Store申請、外部サービスへの送信、決済契約、課金開始をしない。
- ABEMAのアクセス制限や地域制限を回避しない。
- 本番環境で実証していないものを「検証済み」と案内しない。
