## 本文案

株式会社AbemaTV ご担当者様

お世話になっております。

ABEMAのブラウザ視聴中に表示・受信したコメントを、利用者本人のPC内で保存・検索・分析し、投稿者単位のミュートを支援する非公式Chrome拡張機能を個人で開発しています。現在は一般向けに配布・販売しておらず、公開前に利用条件を確認したく、ご連絡いたしました。

機能・仕組みの概要は次のとおりです。

- 利用者が明示的に記録を開始した後、ブラウザ上のABEMAコメント本文・投稿者ID・コメント時刻・ページ情報などを端末内のChrome拡張ストレージへ保存し、検索・分析します。
- コメント履歴は原則最大30日・10万件まで保持し、映像や音声は記録・保存しません。
- ブラウザでABEMA自身が受信するWebSocket／fetch／XHRの応答を観測します。新しいコメントを取得するための独自のサーバー要求・追加巡回・アクセス制限回避を行う設計ではありません。
- 記録がOFFでも、利用者が以前に登録したミュート対象を画面上で非表示にするため、端末内で一部のコメント要素を確認する場合があります。コメント本文の外部サーバーへの自動送信は行いません。
- 将来的に、無料配布、任意の支援受付、追加機能の有料提供を検討していますが、現時点で開始していません。

以下について、差し支えない範囲でご教示いただけますと幸いです。

1. 上記の非公式Chrome拡張を第三者へ無料配布することについて、ABEMAの利用規約その他の条件上、問題となる点はありますか。
2. 表示済みのコメントおよび受信応答の端末内での観測・保存・検索、画面上のミュート制御について、禁止される処理や技術的な制約はありますか。
3. 任意の寄付・支援や、有料追加機能を提供する場合に、別途確認・承諾・契約が必要でしょうか。
4. 「ABEMA非公式」の明示を前提に、機能の対象サービス名としてABEMAの名称を使用する場合の留意点はありますか。

もし担当窓口が異なる場合は、適切な窓口をご案内いただければ幸いです。

お忙しいところ恐れ入りますが、どうぞよろしくお願いいたします。
