# 配布前の確認記録（2026-10-19）

> 開発ブランチでの準備資料。まだ一般配布しない。ABEMAの利用規約への適合を保証するものではない。

## 今回の実装

- `background.js`: Chrome拡張機能の**新規インストール**に限り、コメント記録を停止状態（`captureEnabled: false`）で開始する。更新時は既存の設定を保持する。既存の自動起動設定は変更しない。
- `popup.html`: 「はじめての使い方・データの取り扱い」リンクを追加。
- `guide.html`: 初回起動から分析・記録停止までの説明、保存上限、制約を明示。
- `privacy.html`: 取り扱うデータ、保存先、権限、削除・出力に関する説明。
- `tests/auto-program.test.cjs`: 新規インストールが停止状態になること、アップデート時には記録設定を上書きしないことの回帰テストを追加。

**自動テスト実行結果（2026-10-19）**: GitHub Actionsで単体141件・Playwright模擬ブラウザ11件に成功（[検証ログ](https://github.com/yamada1221/abema-comment-analyzer/actions/runs/39240880446)）。本番ABEMA画面での動作確認はクラウド環境の地域制限で未実施。

### 記録停止時の最小化

- `page-bridge.js`: 記録OFFかつミュート対象なしの場合、コメントDOMのObserver・走査タイマーを止める。
- 記録OFFでミュート対象が存在する場合は、画面上で指定ユーザーを隠すためにDOMを読み取るが、コメント本文の記録・送信はしない。
- 記録ONに切り替えたときだけ通常の収集処理を再開する。コメント一覧の親コンテナではなく、個別のコメント行を隠す修正も実施。
- `tests/dom-consent.test.cjs` でこの三つの条件と、記録OFFでの過去コメント読込拒否を検証。

## 実装とデータの現状（ソースの確認範囲）

- `manifest.json` は `storage`, `tabs`, `alarms`, `unlimitedStorage` と `https://abema.tv/*` のホスト権限を要求。
- `background.js`、`content.js`、`background-capture.js` にChrome拡張機能内部の保存・メッセージ処理がある。
- `network-bridge.js` はABEMA上の通信を観測し、コメント候補を内部メッセージで渡す。独自サーバーへの送信は確認した範囲で実装されていない。
- `dashboard.js` は利用者の明示操作によるJSON/CSV/引継ぎファイルのエクスポートを扱う。
- コメントは最大30日・100,000件。学習用サンプル、タグ、ミュート設定はコメントと同じ条件では削除されない。
- **ソース全体の網羅的なセキュリティ監査が完了したという意味ではない。** Chromeウェブストア申請前に現行コミットで再点検する。

## 手元Chromeでの確認項目（実施待ち）

1. 新規プロファイルでインストールし、初期表示が「記録を開始」で、ABEMAを開いても初回同意前にコメントが保存されない。
2. 「はじめての使い方・データの取り扱い」を開ける。案内内の「分析画面」「データの取り扱い」リンクが動く。
3. ユーザーが「記録を開始」を押した後、ABEMAタブを再読み込みし、コメントを受信・保存できる。
4. 検索、投稿者タグ、リプレイ、ミュート／取り消しが動作し、もとのUIが崩れない。
5. 「記録を停止」により新着収集が止まる。番組自動起動は利用者が有効化するまで開始されない。
6. 既存版から更新して、`captureEnabled`・コメント・タグ・ミュート・番組設定が失われない。
7. JSON/CSV・引継ぎファイルを出力でき、消去操作の違いが案内どおりである。
8. 自動起動、コメント欄を開く処理、タブが閉じたときの動作、切断時の復旧は実放送で確認する。

## Chromeウェブストア向けZIPの事前検査（未公開）

`scripts/package_extension.py` を追加し、拡張機能の実行に必要な21ファイルだけを明示的な許可リストから検証・梱包するようにした。 `node_modules/`、`tests/`、`docs/`、`.github/`、開発メモ、引継ぎファイル等はパッケージに含めない。未公開段階で誤配布しないため、CIでは**検査のみ**行い、ZIPをアップロードしない。

```sh
python3 scripts/package_extension.py --check
# 上記検査が成功し、ローカルでZIPの内容を見る必要がある場合のみ：
python3 scripts/package_extension.py
```

生成先（ローカル）: `dist/abema-comment-analyzer-v0.13.1-review.zip`（manifestのバージョンに追従）。 `dist/` はGitに登録しない。実際にChromeウェブストアへ出すには、別途権利・規約・問い合わせ先・プライバシーポリシー公開URL・審査用画像などが必要。
