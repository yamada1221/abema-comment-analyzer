## 今回の実装

- `background.js`: Chrome拡張機能の**新規インストール**に限り、コメント記録を停止状態（`captureEnabled: false`）で開始する。更新時は既存の設定を保持する。既存の自動起動設定は変更しない。
- `popup.html`: 「はじめての使い方・データの取り扱い」リンクを追加。
- `guide.html`: 初回起動から分析・記録停止までの説明、保存上限、制約を明示。
- `privacy.html`: 取り扱うデータ、保存先、権限、削除・出力に関する説明。
- `tests/auto-program.test.cjs`: 新規インストールが停止状態になること、アップデート時には記録設定を上書きしないことの回帰テストを追加。

**自動テスト実行結果（2026-10-19）**: GitHub Actionsで単体142件・Playwright模擬ブラウザ11件・ZIP生成用Pythonテスト11件の計164件に成功（[検証ログ](https://github.com/yamada1221/abema-comment-analyzer/actions/runs/39244404946)）。本番ABEMA画面での動作確認はクラウド環境の地域制限で未実施。

### 記録停止時の最小化

- `page-bridge.js`: 記録OFFかつミュート対象なしの場合、コメントDOMのObserver・走査タイマーを止める。
- 記録OFFでミュート対象が存在する場合は、画面上で指定ユーザーを隠すためにDOMを読み取るが、コメント本文の記録・送信はしない。
- 記録ONに切り替えたときだけ通常の収集処理を再開する。コメント一覧の親コンテナではなく、個別のコメント行を隠す修正も実施。
- `tests/dom-consent.test.cjs` でこの三つの条件と、記録OFFでの過去コメント読込拒否を検証。

## 実装とデータの現状（ソースの確認範囲）

- `manifest.json` は `storage`, `tabs`, `alarms`, `unlimitedStorage` と `https://abema.tv/*` のホスト権限を要求。
- `background.js`、`content.js`、`background-capture.js` にChrome拡張機能内部の保存・メッセージ処理がある。
- `network-bridge.js` はABEMA上の通信を観測し、コメント候補を内部メッセージで渡す。独自サーバーへの送信は確認した範囲で実装されていない。
- `dashboard.js` は利用者の明示操作によるJSON/CSV/引継ぎファイルのエクスポートを扱う。
- コメントは最大30日・100,000件。学習用サンプル、タグ、ミュート設定はコメントと同じ条件では削除されない。
- **ソース全体の網羅的なセキュリティ監査が完了したという意味ではない。** Chromeウェブストア申請前に現行コミットで再点検する。

## CSVの数式解釈対策（2026-10-19）

- 収集したコメント本文・投稿者ID・番組名は外部由来であり、CSVをExcel等で開いたときに `=`、`+`、`-`、`@` で始まる値を数式と解釈されるおそれがある。
- `csv-export.js` に数式として解釈され得る先頭文字（先頭空白・制御文字も含む）のアポストロフィ付加、引用符のCSVエスケープ、UTF-8 BOMおよびCRLF改行を実装。既存のJSONデータや保存コメントは変更しない。
- `tests/csv-export.test.cjs` は単体テスト3件を追加。 `tests/browser/csv-export.test.cjs` はレビューZIPをChromeに読み込み、悪意ある数式風のコメントを実際にCSVでダウンロードし検証する。
- レビューZIPのファイル数を26件に更新し、必要なスクリプトのみ梱包する。
- [GitHub Actions成功結果（コード変更時）](https://github.com/yamada1221/abema-comment-analyzer/actions/runs/39254242736)：Python 12件・Node.js 145件・模擬Chrome 14件、合計**171件成功／失敗0**。
- 注：数式インジェクションの解釈は表計算ソフトやインポート操作に依存する。全ソフトでの安全性を保証するものではなく、開く側も出所不明のCSVには注意が必要。
