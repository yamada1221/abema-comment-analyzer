# 2026年10月19日：ABEMA・Chrome Web Store 適合性確認

> 配布前の開発メモ。法的な許諾やChromeウェブストア審査通過を確認したものではありません。**一般配布・寄付募集・課金は保留**します。

## Chromeウェブストアで確認できたこと

2026年7月1日にChrome開発者向けブログが、ユーザーデータの収集について新たな開示要件を告知。**2026年8月1日から適用**され、個人情報・閲覧内容等を含むユーザーデータの収集は拡張の単一目的に必要な範囲に限られ、収集内容の目立つ場所での開示と、ユーザーの事前同意が必要です。

- [Chrome Web Store policy updates (2026-07-01)](https://developer.chrome.com/blog/cws-policy-updates-2026)
- [Chrome Web Store ユーザーデータのトラブルシューティング](https://developer.chrome.com/docs/webstore/troubleshooting)
- [Chrome Web Store ユーザーデータFAQ](https://developer.chrome.com/docs/webstore/user_data)

現在の対応:
- 新規インストール時のコメント記録をOFFにするだけでなく、**保存フラグが未確定の場合も記録しない**ように修正した。更新時は古い暗黙のON設定をONへ移行し、既存利用者の記録選択を変えない。
- ポップアップの「記録を開始」の前に、収集データ（コメント本文、投稿者ID、日時、ページ情報）とローカル保存・開発者への非送信を表示。ストレージ読込完了前はボタンを無効化。
- 引き続き公開URLのプライバシーポリシー、配布者の連絡先、データ開示項目、Chrome Web Storeの許可権限の説明を準備する。

注意: `network-bridge.js` のフック自体はページ読込時点で設置されるものの、記録OFF中は通信応答の解析・診断送信を抑止し、ON/OFFの変更を追従する処理とテストを追加した。一方で、`page-bridge.js` のコメント要素走査は記録停止中もミュート機能等のために動く可能性があり、**初回の明示同意前にどの処理を許容するか、ミュートだけ利用したい場合の扱いは未解決**。許可範囲を確認できるまで一般配布しない。

## ABEMAについて確認できたことと未確認事項

公式の利用規約ページ: https://abema.tv/about/terms

公式ヘルプは、外部ツールによる**映像コンテンツの不正な録画・保存**は規約違反になると説明している。ただし本拡張は映像の録画をせず、**コメント本文を端末内に保存して分析**する。これにより問題がないと断定することはできない。

- [ABEMAヘルプ：基本操作・便利機能](https://help.abema.tv/hc/ja/articles/360023117251-%E5%9F%BA%E6%9C%AC%E6%93%8D%E4%BD%9C-%E4%BE%BF%E5%88%A9%E6%A9%9F%E8%83%BD%E3%81%AB%E3%81%A4%E3%81%84%E3%81%A6)
- [ABEMA：利用規約](https://abema.tv/about/terms)

この環境では現行利用規約ページの本文を取得できず、コメント保存・第三者配布・商用提供が許可されているかは**未確認**。当面は「規約違反でない」「配布・販売できる」などと案内しない。

### ABEMAへの問い合わせ候補（送信はしていない）

- ABEMAの表示・受信したコメント本文と投稿者IDを、利用者のPC内だけに最大30日保存し、検索・タグ付け・ミュートする非公式Chrome拡張について、許容範囲と制約はあるか。
- ABEMA本体のfetch/XHR/WebSocket応答を観測するが追加のリクエストは行わない設計でも、技術上・規約上の問題はあるか。
- 無料の一般配布、任意の寄付募集、有料追加機能について、条件や承諾は必要か。
- ABEMAの名称の説明目的での使用や、サイトへの案内リンクに条件があるか。

承認または回答が得られるまで、非公式であることを明示し、商用化の判断は保留する。
