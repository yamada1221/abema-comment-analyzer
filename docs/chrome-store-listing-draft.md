# Chromeウェブストア掲載文案・申請準備（公開前）

作成日：2026-10-19 / 状態：**草案。申請・公開していない。**

## 掲載名（案）

ABEMAコメント分析（非公式）

## 短い説明（案）

ABEMAの表示コメントを端末内で記録し、本文検索・投稿者タグ・リプレイ・ミュートができる非公式Chrome拡張。

## 詳しい説明（案）

ABEMAコメント分析は、PC版ChromeでABEMAを視聴する際に、受信したコメントをブラウザ内で整理・振り返るための非公式拡張機能です。

**主な機能**
- コメント本文に一致した投稿だけを検索し、番組・時刻・ユーザータグで絞り込む
- 投稿者ごとの傾向や投稿数を一覧で確認する
- ユーザーにタグを付け、指定ユーザーのコメントを画面上で非表示にする
- 記録したコメントを時系列でリプレイする（動画・音声の再生や保存ではありません）
- 連投や同文反復などの条件から自動ミュートの候補・判定を管理する
- 保存したデータのJSON/CSV出力と引継ぎ

**データの取り扱い**

新規インストール時には記録を開始しません。利用者が「記録を開始」を押すと、受信できたコメントの本文・投稿者ID・時刻・ページ情報などをそのPCのChrome拡張ストレージへ保存します。新着保存時に30日より前の履歴を除外し、最新10万件に整理します。記録停止中やChrome終了中は期限だけでは自動削除しません。端末内で検索・集計し、開発者管理サーバーへの自動送信はありません。

記録OFFでも、既に登録したミュート対象があれば、対象投稿を非表示にするため画面上のコメントを一時的に参照します。コメント履歴としては保存しません。ミュート対象がなく、記録もOFFの場合、拡張機能のコメント走査は停止します。

**注意事項**

- ABEMA公式とは関係ありません。ABEMAが提供するコメントの表示・接続方式に依存します。
- 映像や音声は録画・ダウンロードしません。
- スマートフォンのABEMAアプリでは動きません。PC版Chrome向けです。
- ABEMA側の仕様変更や地域制限により、一部の機能が動作しない場合があります。

## 権限を使う理由（審査用説明案）

- `storage`: コメント履歴・タグ・設定をChrome内に保存する。
- `unlimitedStorage`: 最大10万件までのコメント履歴を保存するため、Chrome拡張の通常の保存容量上限を超える可能性がある。
- `alarms`: 利用者が有効にした指定番組の記録時刻を定期的に確認する。
- `https://abema.tv/*`: ABEMA上のコメント表示・接続の観測、ミュート表示、コメント欄操作、ABEMAタブのURL・タイトルの確認と状態管理に利用する。全サイトの情報を取得する `tabs` 権限は要求しない。
- `MAIN` worldのページスクリプト: サイト自身の通信・表示情報を扱うために使う。追加リクエストによる網羅的な収集を目的としない。
