投稿者の分析へ

上の分析時間内で、一致したコメントだけを表示します。全半角・大文字小文字を区別せず、入力した語句全体で部分一致します。投稿者タグの条件とも組み合わせられます。

ユーザータグの自動付与

保存履歴のコメントから「絵文字のみ」「URLあり」「同文反復（同じ本文を3件以上）」「高頻度投稿（自動ミュート設定の件数・秒数）」を投稿者のタグに追加します。手動タグと合わせて12個まで。タグでの検索・絞り込み・編集に使えます。タグ付けだけではミュートしません。

タグは履歴の保存期限後や自動付与をOFFにした後も残ります。ユーザータグから外して保存した名前は、その人には自動で付け直しません。再び付ける場合は手動で追加してください。

保存コメントのリプレイ

読み込んだ時点の検索結果を投稿時刻順に再生します。新着は混ざりません。本文の保存範囲が対象で、映像の再生は含みません。別タブへ移ると一時停止します。

自動ミュート

件 / 秒でミュート
回 / 秒でミュート
件以上 / 秒

判定時間内の取得済み投稿がすべて絵文字の場合にミュート。1件にすると1投稿から判定します。通常文・数字だけ・顔文字は対象外です。初期値はOFF。

学習型ミュート

文字2〜3gramのTF-IDFを使い、通常ユーザーにも多い表現は減点します。処理は端末内だけで行います。学習用サンプルは履歴と別に最大200人・各40件を保存します。古い学習元の重みは30日で半分になり、180日を超えたサンプルは学習対象から外れます。ミュート解除・除外した人のサンプルは削除します。

「指定文との類似度」は、問題コメントを個別指定した場合だけ使います。低くすると言い換えを拾いやすくなりますが、誤推薦も増えます。

指定した学習コメント

指定がある間は、その文章だけを学習元に使います。1件から利用でき、設定した類似度以上の投稿が2件以上あるユーザーを候補にします。比較対象の必要コメント数・除外設定も適用します。指定する操作はミュート設定を変更しません。

指定した文章を確認・解除 0 / 200件

指定した文章は最大200件まで、履歴の保存期限やミュート解除後も残ります。不要になった指定はここで解除できます。引継ぎデータにも含まれます。指定をすべて解除すると、従来のミュート済みユーザーからの学習に戻ります。

学習型ミュート候補

自動ミュート履歴

取り消すと、そのユーザーのミュートを解除し、ミュート済みユーザーから自動保存した学習元を削除して自動判定から除外します。同じユーザーの他の自動判定も取り消し済みになります。手動でもミュートしている場合は解除されます。
